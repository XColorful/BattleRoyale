## 文字流程

1. 什么是解耦，设计API接口
2. 功能简单的方块/指令/物品——实质是如何组织文件（目录）+实现简单功能
3. 文档框架——本模组文档，为复杂设计准备（使之后做起来更清晰）
4. 复杂的游戏机制——本模组设计
5. 专精于某个机制——参考TaCZ
6. 提供开放的API，以学习模组联动/给别人提供API
