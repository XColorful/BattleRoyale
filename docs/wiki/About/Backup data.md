# 备份数据

备份数据位于 _./minecraft/battleroyale/backup_ 下的所有json文件

- 模组的备份数据独立于Minecraft的存档数据，全存档统一

## 配置备份
_./minecraft/battleroyale/backup/config_

- 由[备份配置](https://github.com/XColorful/BattleRoyale/wiki/Backup-command)生成，文件结构同 _./minecraft/config_
- 仅包含模组的配置文件

# English

Backup data directory located in all json files under _./minecraft/battleroyale/backup/config_

- The mods' temporary data is separate from Minecraft's save data, all saves are unified

## Config backup
_./minecraft/battleroyale/backup/config_

- Generated by [Backup command](https://github.com/XColorful/BattleRoyale/wiki/Backup-command#English), with the same file structure as _./minecraft/config_
- Contains only the mod's configuration files
