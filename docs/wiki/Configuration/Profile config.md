# 预设配置

## 单个配置

- id：预设配置唯一id
- name：为该配置命名，可重复
- color：暂时没有功能
```json
{
	"id": 0,
	"name": "Default profile",
	"color": "#FFFFFF",
	"modConfigManager": {
		模组配置
	}
}
```

## 模组配置

由[保存配置预设](https://github.com/XColorful/BattleRoyale/wiki/Utility-command#保存配置预设)自动生成
- 该配置不会在[切换配置](https://github.com/XColorful/BattleRoyale/wiki/Config-command#服务端配置)时自动应用，需要手动[应用预设配置](https://github.com/XColorful/BattleRoyale/wiki/Utility-command#应用预设配置)

如需深入了解，详见[模组配置框架](https://github.com/XColorful/BattleRoyale/blob/HEAD/docs/architecture/config/mod-config-framework.md)：
- configManager：主配置管理器，包含若干子配置管理器
- configSubManager：子配置管理器，包含若干文件夹ID，默认仅包含0
```json
"modConfigManager": {
	"configManager": {
		"effect": {
			"performance": {
				"0": {
					"fileName": "example",
					"id": 0
				}
			}
		},
		"game": {
			"gamerule": {
				"0": {
					"fileName": "example",
					"id": 0
				}
			},
			"spawn": {
				"0": {
					"fileName": "example",
					"id": 0
				}
			},
			"zone": {
				"0": {
					"fileName": "example",
					"id": 0
				}
			}
		},
		"server": {
			"performance": {
				"0": {
					"fileName": "example",
					"id": 0
				}
			},
			"utility": {
				"0": {
					"fileName": "example",
					"id": 0
				}
			}
		}
	},
	"configSubManager": {
		"loot": {
			"0": {
				"fileName": "example_loot_spawner",
				"id": 0
			},
			"1": {
				"fileName": "example_entity_spawner",
				"id": 0
			},
			"2": {
				"fileName": "example_airdrop",
				"id": 0
			},
			"3": {
				"fileName": "example_airdrop_special",
				"id": 0
			},
			"4": {
				"fileName": "example_secret_room",
				"id": 0
			},

	}
}
```

# English

## Single Configuration

- id: unique profile id
- name: name the config, can be repeated
- color: no function for now
```json
{
	"id": 0,
	"name": "Default profile",
	"color": "#FFFFFF",
	"modConfigManager": {
		MOD CONFIG
	}
}
```

## Mod config

Automatically generated by [Save config profile](https://github.com/XColorful/BattleRoyale/wiki/Utility-command#Save-config-profile)
- This configuration will not be automatically applied upon [Switch config](https://github.com/XColorful/BattleRoyale/wiki/Config-command#Server-config); it must be manually applied via [Apply profile config](https://github.com/XColorful/BattleRoyale/wiki/Utility-command#Apply-profile-config)

For further details, see [Mod Config Framework](https://github.com/XColorful/BattleRoyale/blob/HEAD/docs/architecture/config/mod-config-framework.md)：
- configManager: Main Config Manager, contains several sub-config managers
- configSubManager: Sub Config Manager, contains several folder IDs, defaults to only containing 0
