### 游戏规则管理器
> _IGameruleManager_

# English

### Gamerule manager
> _IGameruleManager_

> _/battleroyale api gameruleManager [...]_

#### Get gamemode ID
> _/battleroyale api gameruleManager getGameMode_

- `return value`: game mode specified in the current [Vanilla gamerule](https://github.com/XColorful/BattleRoyale/wiki/Gamerule-config#Vanilla-gamerule)
