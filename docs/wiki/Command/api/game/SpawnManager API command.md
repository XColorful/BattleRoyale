### 出生管理器
> _ISpawnManager_

> _/battleroyale api spawnManager [...]_

##### 再出生
> _/battleroyale api spawnManager respawn [player]_

- player：用实体选择器选中并获取游戏玩家列表
- 若游戏玩家列表为空，`返回值`为 0
- `返回值`：获取的游戏玩家数量

# English

### Spawn manager
> _ISpawnManager_

> _/battleroyale api spawnManager [...]_

##### Respawn
> _/battleroyale api spawnManager respawn [player]_

- player: selects game player list using an entity selector
- If the game player list is empty, the `return value` is 0.
- `return value`: the number of game players retrieved
