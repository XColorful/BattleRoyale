# 备份配置
_/battleroyale backup [loot/game/effect/client/server] [subType]_

需要权限等级2

将已加载的配置文件备份至 _./minecraft/battleroyale/backup_ 下
- **覆盖**已有备份文件
- 不删除各路径下其他文件

# English

_/battleroyale backup [loot/game/effect/client/server] [subType]_

Require permission level 2

Backup the currently loaded config files to _./minecraft/battleroyale/backup_
- **Overwrite** existing backup files
- Do not delete other files in each path

## Backup all config
_/battleroyale backup_
