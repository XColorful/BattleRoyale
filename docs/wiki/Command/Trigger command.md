### 触发器
_/battleroyale trigger [protocol]_

发送`TRIGGER_EVENT`：
- protocol：字符串

#### 完整触发器
_/battleroyale trigger [protocol] [pos] [int] [double] [boolean]_

- pos：坐标
- int：整型
- double：双精度浮点数
- boolean：布尔值
- `返回值`：事件是否被取消

## Trigger event
_/battleroyale trigger [...]_

### Trigger
_/battleroyale trigger [protocol]_

Send `TRIGGER_EVENT`:
- protocol: string

#### Full trigger
_/battleroyale trigger [protocol] [pos] [int] [double] [boolean]_

- pos: coordinates
- int: integer
- double: double-precision floating point
- boolean: boolean
- `return value`: whether the event was canceled
