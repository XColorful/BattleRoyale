# 能量指令
_/battleroyale boost [player/clear] [amount/player]_

需要权限等级2

## 补充能量
_/battleroyale boost player [amount]_

### 补充玩家能量
_/battleroyale boost player [amount]_

补充选中玩家能量

- amount：能量数

## 清除能量
_/battleroyale boost clear [player]_

需要权限等级3

### 清除所有能量
_/battleroyale clear_

清除所有实体能量

### 清除玩家能量
_/battleroyale boost clear [player]_

清除选中玩家能量

# English
_/battleroyale boost [player/clear] [amount/player]_

Require permission level 2

## Add Boost
_/battleroyale boost player [amount]_

### Add player boost
_/battleroyale boost player [amount]_

Adds boost to the selected player(s)

- amount: boost amount

## Clear Boost
_/battleroyale boost clear [player]_

Requires permission level 3

### Clear all boost
_/battleroyale clear_

Clear boost for all entities

### Clear player energy
_/battleroyale boost clear [player]_

Clears boost for the selected player(s)
