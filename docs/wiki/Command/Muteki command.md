# 无敌指令
_/battleroyale muteki [player/clear] [time/player]_

需要权限等级2

## 添加无敌效果
_/battleroyale muteki player [time]_

### 添加玩家无敌效果
_/battleroyale muteki player [time]_

使指定玩家无敌一段时间，上限10秒

- time：无敌时间

## 清除无敌效果
_/battleroyale muteki clear [player]_

需要权限等级3

### 清除所有无敌效果
_/battleroyale muteki clear_

清除所有实体无敌效果

### 清除玩家无敌效果
_/battleroyale muteki clear [player]_

清除选中玩家无敌效果

# English
_/battleroyale muteki [player/clear] [time/player]_

Require permission level 2

## Add Invincibility Effect
_/battleroyale muteki player [time]_

### Add player invincibility effect
_/battleroyale muteki player [time]_

Grants invincibility to the specified player(s) for a period, with a maximum duration of 10 seconds

- time: The duration of invincibility

## Clear Invincibility Effect
_/battleroyale muteki clear [player]_

Requires permission level 3

### Clear all invincibility effects
_/battleroyale muteki clear_

Clears invincibility for all entities

### Clear player invincibility effect
_/battleroyale muteki clear [player]_

Clears invincibility for the selected player(s)
