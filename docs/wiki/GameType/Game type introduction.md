# 游戏类型说明
基于模组提供的高自定义区域配置，可模拟各种玩法，大致分成几类
- 对于可复用的区域配置，通常只需修改初始区域词条即可
- 每阶段区域id以0，1x，2x命名以更好辨别
- 对于可复用的区域配置，1x及以后均使用 _previous_ 或 _relative_ 类型

# English
Based on the highly customizable zone configurations provided by the mod, various gameplay modes can be simulated, broadly categorized into several types.
- For reusable zone configurations, usually only the initial zone entry needs to be modified.
- Each phase's zone id is named 0, 1x, 2x for better identification.
- For reusable zone configurations, 1x and later use _previous_ or _relative_ types.

## Competitive Mode
Intense and thrilling combat experiences.

### Battle Royale
Classic last-man-standing gameplay.

- [Team Battle Royale](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Team-Battle-Royale): 4-player team last-man-standing.
- [Hunger Games](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Hunger-Games): Solo last-man-standing.
- [Vanilla Survival](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Vanilla-Survival): Primitive survival last-man-standing.

### Territorial Conquest
Long-range engagements.

- [Tribal Warfare](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Tribal-Warfare): Abundant initial resources.

### Area Compression
Crowded experiences for everyone.

- [Shifting Fates](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Shifting-Fates): Ring-shaped marathon.
- [Zone Purge](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Zone-Purge): Four-way forced combat.
- [Quadrant Reunion](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Quadrant-Reunion): Four paths converging for a decisive battle.
- [Spiral Containment](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Spiral-Containment): Mosquito coil-style shrinking circles.

### Team Battle
Don't hit your teammates.

- [Annihilation](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Annihilation): Classic team deathmatch.
- [Grand Battlefield](https://github.com/XColorful/BattleRoyale/wiki/Competitive-Mode#Grand-Battlefield): Large-scale team deathmatch.

## Asymmetric Competitive
Unique experiences for each faction.

### The Hunt
Factions with vastly different strengths.

- [The Killing Hour](https://github.com/XColorful/BattleRoyale/wiki/Asymmetric-Competitive#The-Killing-Hour): 99 vs 1.
- [Reversal of Fortune](https://github.com/XColorful/BattleRoyale/wiki/Asymmetric-Competitive#Reversal-of-Fortune): 1 vs 99.

## PVE Mode
Players cooperate to fight monsters.

### Survival Focus
Just survive.

- [Doomsday Survival](https://github.com/XColorful/BattleRoyale/wiki/PVE-Mode#Doomsday-Survival): Run if you can't fight.

### Endless Resistance
A large wave of monsters is approaching.

- [Challenge Mode](https://github.com/XColorful/BattleRoyale/wiki/PVE-Mode#Challenge-Mode): Fixed-point monster killing.
- [Raid Mission](https://github.com/XColorful/BattleRoyale/wiki/PVE-Mode#Raid-Mission): Monster killing everywhere.

## Casual Mode
Reduced competitive pressure, increased interactivity.

### Dash
Dash!

- [The Fastest Legend](https://github.com/XColorful/BattleRoyale/wiki/Casual-Mode#The-Fastest-Legend): Be swallowed if you fall behind.

### Chase & Escape
Police catch thieves.

- [Race Against Time](https://github.com/XColorful/BattleRoyale/wiki/Casual-Mode#Race-Against-Time): Parkour duel.
- [Invisible Hustle](https://github.com/XColorful/BattleRoyale/wiki/Casual-Mode#Invisible-Hustle): Nimble hide-and-seek.
- [Maze Expedition](https://github.com/XColorful/BattleRoyale/wiki/Casual-Mode#Maze-Expedition): Reversal with a powerful weapon.

## Game config add-on
Combined with different game types.

### Special Functions
Independent functions, can be mixed into games.

- [Circle in Circle](https://github.com/XColorful/BattleRoyale/wiki/Game-config-add-on#Circle-in-Circle): Determine the shrinking endpoint in advance.
- [Blockade Beams](https://github.com/XColorful/BattleRoyale/wiki/Game-config-add-on#Blockade-Beams): Randomly generated interference pillars.
- [Expulsion Beams](https://github.XColorful/BattleRoyale/wiki/Game-config-add-on#Expulsion-Beams): Interference pillars emitted from the center.
- [Multifunctional Zone](https://github.com/XColorful/BattleRoyale/wiki/Game-config-add-on#Multifunctional-Zone)：Multi-function zone in the same phase.
